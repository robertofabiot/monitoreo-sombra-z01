# Monitoreo de sombra · Zona Z01

Prototipo del producto mínimo viable del Proyecto Integrador de Educación Ambiental (Grupo 4, Universidad Americana).

Página web de un solo archivo (HTML, CSS y JavaScript, sin servidor) para registrar conteos de asientos con sombra en la zona Z01, calcular el porcentaje de asientos con sombra por horario y exportar los registros en CSV.

- Abrir directamente el formulario: `index.html#formulario`
